# 🎓 Student Registration System (Day 8 Upgrade)

## 📌 Description
A modern student registration system built using PHP and Bootstrap.

## 🚀 Features
- Photo upload UI (preview only)
- Gender selection
- Course dropdown
- Address textarea
- Strong validation
- Styled confirmation page with gradient UI
- Bootstrap + Font Awesome design

## 🛠 Tech Used
- HTML
- CSS (Bootstrap)
- PHP

## ▶️ How to Run
1. Install XAMPP
2. Place folder in htdocs
3. Start Apache
4. Open http://localhost/day8-project
